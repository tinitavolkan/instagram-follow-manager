# Güvenlik bildirimleri

Desteklenen yayın: `0.1.x`.

Güvenlik açığı veya hassas veri bulursan depodaki **Security → Report a
vulnerability** bölümünü kullan. Bu seçenek açık değilse gerçek ayrıntıyı
paylaşmadan, özel bildirim kanalı istediğini belirten bir issue aç.

Parola, çerez, API anahtarı, gerçek dışa aktarım veya oturum profili paylaşma.
Yalnız anonimleştirilmiş tekrar oluşturma adımlarını ve gerekli küçük örneği ekle.

Bu uygulama Instagram'dan bağımsızdır. Yerel tarayıcı profili hassas veri içerir;
program veya kaynak kod paylaşılırken profil klasörü dahil edilmemelidir.
